# Default dictionary sources

## Japanese-English lookup and word forms

- `romaji-english-jmdict-2026-11-02.json.gz` is a compact lookup derived from the English-only JMdict dataset distributed by [jmdict-simplified](https://github.com/scriptin/jmdict-simplified), release `3.6.2+20261102210542` (dictionary date 2026-11-02). It contains 207,169 romaji keys, 483,623 distinct reading-gloss associations, 32,817 inflectable lemmas, and 627 form rules for common modern conjugations. It expands in memory when first used. The popup groups meanings by dictionary entry and shows up to four likely results, including applicable form explanations.
- JMdict is maintained by the Electronic Dictionary Research and Development Group (EDRDG). The underlying data is copyright © James William Breen and EDRDG, and is provided under the [EDRDG license](https://www.edrdg.org/edrdg/licence.html) and [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The jmdict-simplified release asset is a JSON conversion of that data.
- The preserved source archive is `dictionaries/source-data/jmdict-eng-3.6.2+20261102210542.json.tgz`. A second preserved source, `dictionaries/source-data/ja_full-OpenSubtitles2018.txt`, comes from [FrequencyWords](https://github.com/hermitdave/FrequencyWords) and is based on OpenSubtitles 2018. Its content is CC BY-SA 4.0. Corpus counts help rank written homographs; they do not provide exact frequencies for each sense.
- The preserved `dictionaries/source-data/tkg-entries-index-32c267cb.json` is the 15.0 MB [TKG Japanese-English Learner's Dictionary](https://github.com/tkgally/je-dict-1) entry index at commit `32c267cbfa7756a2e3542657772759d92d4e2420` (CC0 1.0). Its basic and core tiers add a learner-priority bonus when both a Japanese spelling and reading match a JMdict entry. This makes ordinary meanings of ambiguous romaji such as `matte` (wait), `kitta` (cut), and `hashi` (bridge/chopsticks) more visible. The tier bonus is a heuristic, not a measured frequency for each sense.
- Run `node scripts/build-romaji-lookup.mjs` to rebuild from those sources. `scripts/japanese-inflections.mjs` defines form rules from JMdict part-of-speech tags. The browser checks those rules against matching lemmas, so a form such as `chikazuite` can identify `chikazuku`. It also handles suru nouns, common adjective forms, copula forms, and some group suffixes. The group suffix lookup accepts only JMdict entries with a clearly animate English head gloss; it can miss valid words whose gloss does not meet that conservative filter. Potential forms of known stative exceptions and irregular honorific polite stems follow [Amherst College's conjugation guidance](https://wtawa.people.amherst.edu/jvrules/index.php?form=potential), [including its polite-stem exceptions](https://wtawa.people.amherst.edu/jvrules/index.php?form=stemmasu). Archaic forms and longer auxiliary chains are outside this rule set. The derived data is distributed under the same attribution and share-alike terms as its sources.
- The popup raises the common `to` particle senses (and, with, quotation) from the retained JMdict glosses; [TKG's basic vocabulary list](https://www.tkgje.jp/lists/basic.html) independently confirms those senses. `tests/independent-translation-reference.test.js` pins further lexical and conjugation examples to public TKG, Japan Foundation, Japanese Audio Lessons, Amherst College, and Umeda references. `tests/independent-ranking.test.js` checks common-first ordering against the preserved TKG tiers. TKG is independent of this JMdict lookup pipeline, but its entries are AI-assisted, so these tests are cross-checks rather than proof that every gloss or ranking is correct. The four-result popup can still omit meanings retained in the full lookup, and the source counts and tiers do not measure individual sense frequency.

## Sets

- `most-common-50-es.json` is a Spanish translation of the 50-card starter set, including its example sentences and contextual word annotations. The historical `english` field name remains in the file because it is required by the app's dictionary format. It is generated by `node scripts/build-spanish-starter-50.mjs`. The larger starter sets and the general romaji lookup remain in English; their entries are explicitly marked as English in the Spanish starter catalog. Loading a set replaces the currently saved dictionary only after the existing confirmation.

- All five sets follow the frequency order in [Noos's Japanese frequency list](https://noosflashcards.com/resources/frequency-lists/japanese), based on Leipzig Corpora Collection news counts. They skip duplicate romaji and entries that have no corresponding TKG entry with a complete, sense-tagged example. The published sets are prefixes of the same filtered order; the 2,000-word set reaches source rank 2,426 after filtering.
- English glosses and example sentences for all sets come from the [TKG Japanese-English Learner's Dictionary](https://www.tkgje.jp/) and its [public data repository](https://github.com/tkgally/je-dict-1). Each chosen example is tagged to the definition used for that card. The example source is converted to kana and romaji for this app.

## Contextual example translations

The default decks store one `wordMeanings` annotation for each visible romaji word in an example. The annotations are positional, so identical spellings in different sentences or positions can display different English meanings. When a revealed default card shows an annotated example, the popup uses that sentence's single meaning. Imported and user-written examples without annotations still use the general JMdict lookup.

Joined and separately written te-form plus iru constructions identify their component forms and whether the ending is polite, past, or negative. Their popup also describes continuing actions or states; some such expressions describe a resulting state rather than an action happening at this moment. Separately written te-form and auxiliary tokens share their contextual popup.

Recognized suru compounds also identify past, negative, and polite endings. The split expression `arigatou gozaimashita` shares one popup that identifies `gozaimashita` as polite past. Similar spellings are checked against their dictionary entries, so unrelated words such as `ashita` retain their own meanings.

Recognized passive constructions such as `kaketsusareta` and `dounyuu sareta` explain the passive form and its contextual meaning. Predicate uses of na-adjectives identify the adjective and the accompanying copula; both words share the same popup. The [Japan Foundation's teaching notes](https://marugoto.jpf.go.jp/assets/docs/teacher/resource/elementary2_c/elementary2_competences_teachers_notes.pdf) describe the distinction between past passive and continuing state, and the [National Institute for Japanese Language and Linguistics](https://www2.ninjal.ac.jp/npcmj/pdf/npcmj_annotation_manual_en_20200501.pdf) identifies the na-adjective plus copula predicate.

The annotations come from the [TKG public data repository](https://github.com/tkgally/je-dict-1) at commit `32c267cbfa7756a2e3542657772759d92d4e2420`. The complete owner entries for candidate cards and all entries linked in their examples are preserved in `dictionaries/source-data/tkg-example-entries-32c267cb-*.json.gz` and `tkg-linked-entries-32c267cb-*.json.gz`, with manifests recording archive hashes. These archives keep the original entry JSON, including sentence links, definitions, and sense tags. They are retained for later corrections and regeneration.

The source example's sense tag identifies the card word's meaning. Inline links identify other words' dictionary entries; those links generally identify a word rather than its particular sense. The annotation script uses the linked entry's definitions and the sentence context to choose one English explanation. A lexical match alone can be misleading for particles, auxiliary verbs, and homographs, so `tests/contextual-example-meanings.test.js` checks representative cases against the preserved source entries.

There are 9,565 annotated word targets in the 2,000-card deck, and 17,295 occurrences across all five decks. All five decks are exact prefixes of the 2,000-card deck. Two ambiguous examples were replaced with examples carrying a single source sense, and 131 exact romaji spacing corrections separate previously fused words.

`scripts/default-example-meaning-overrides.json` preserves 676 sentence-specific editorial decisions, including reviewed ambiguous choices and corrections. The original review queue is retained as `source-data/tkg-context-editorial-input-32c267cb.json`, alongside its correction decisions in `scripts/context-review-decisions.json`. Unflagged choices use source sense tags, grammar rules, or English-context scoring. Complete coverage and zero pending review flags do not prove that every semantic choice is correct; the independent regression sentences check selected difficult cases, and future corrections can be added without rebuilding the general dictionary. Index-only TKG citations have no numbered sense; JMdict and editorial glosses omit a TKG citation when it would identify a different word.

## Example selection and limits

The generator only accepts a TKG example when its `sense_numbers` includes the selected definition, the Japanese source can be converted to a kana reading without leftover kanji, the Japanese text ends as a complete sentence, and a non-placeholder English translation is present. The smaller new sets use prefixes of the filtered 2,000-word sequence.

Example romaji is spaced using TKG's source annotations, which mark word boundaries. A one-time script matched all 3,650 stored example records to the source text, then changed only their romaji spacing; the existing hiragana and translations were preserved. It verified that removing spaces from each result leaves the original romaji unchanged (ignoring an `n'` separator immediately before a space).

These checks preserve the source's sense alignment and remove incomplete samples, but they cannot prove that every translation is error-free. The TKG project describes its entries as reviewed and refined; the 2,000 examples have not each received an independent human proofread for this app.

## Regenerating the files

The generator uses Node.js and locally downloaded source files. From the project root, pass the extracted TKG repository, its generated `entries_index.json`, and Noos's UTF-8 `japanese-top-5000.csv` file:

```sh
node scripts/generate-default-dictionaries.mjs -- <project-root> <tkg-repository-root> <entries_index.json> <japanese-top-5000.csv>
```

To reapply the example spacing to already generated files, run:

```sh
node scripts/space-example-romaji.mjs <project-root> <tkg-repository-root>/entries --write
```

To regenerate the contextual word meanings from the preserved TKG archives, first run the annotation script without `--write` to inspect its coverage and review report. Then run it with `--write` after resolving any flagged cases:

```sh
node scripts/annotate-default-examples.mjs --report=dictionaries/source-data/tkg-context-review-32c267cb.json
node scripts/annotate-default-examples.mjs --write
node scripts/annotate-default-examples.mjs --check
```

`scripts/download-tkg-example-sources.mjs` can verify or resume the pinned archives if needed. It preserves downloaded files and checks their hashes. Run it once for card source entries and again with `--linked-targets` for their linked words.
